Admin panel

All 15 screens of the admin panel. On a phone, tap any screen to open it full size. The admin no longer approves bookings, and now owns nurse availability, the booking rules and cancellations.

A1 to A3. Sign in NO CHANGE

Admin login, forgot password and reset password.

A4. Dashboard CHANGED

Since nothing waits for approval any more, the dashboard only raises the cases where the system could not finish on its own.

A5. Bookings CHANGED

The Confirm button is gone. Every paid booking arrives already confirmed with a nurse. The admin's two actions are Reassign and Cancel.

A6. Booking detail CHANGED

Everything about one booking. Shows which gender the user asked for, the nurse the system picked, and a history of what happened automatically.

A7. Reassign nurse NEW

Replaces the old Confirm dialog. The admin swaps the nurse without cancelling the booking.

A8. Kill switch: cancel a booking NEW

Opens from the red Cancel button. Works on any booking that is not already completed or cancelled, including a visit that has started.

A9. Nurse unavailable: handle many bookings at once NEW

For when a nurse falls sick or leaves. One step moves every affected booking to another nurse where possible, and cancels with a refund where not.

A10. Nurses, with add and edit form CHANGED

Every nurse has a gender. A nurse is offered to users only when gender and working hours are both filled in.

A11. Nurse availability NEW

The admin sets when each nurse works. Weekly hours are the normal pattern. The calendar is for leave and one-off changes.

A12. Services, with add and edit form NO CHANGE

The list of services users can book, and their hourly price.

A13. Settings NEW

The booking rules. Changes apply to the user app immediately, with no app update.

A14. Profile NO CHANGE

The admin's own account details and password.

A15. Help CHANGED

Short guides for the admin, updated for the new cancel and availability steps.

Messages NEW

With no nurse app, SMS and email are how the nurse works. These are the messages the system sends by itself. Wording is a sample.

To nurse: new visit (SMS + email)
CareNest: New visit #1042. Sat 10 Oct, 3:00 PM, 4 hours. Elder care. Patient R. Sharma, 68, M. Phone 98xxxxxx11. H. No. 221, Sector 14, Bareilly, near City Park gate. Directions: maps link

Sent the moment the user pays. The link opens the exact pin in Google Maps on any phone.

To nurse: visit moved to someone else
CareNest: Visit #1042 on Sat 10 Oct, 3:00 PM is no longer assigned to you.

Sent when the admin reassigns (screen A7).

To nurse: visit cancelled
CareNest: Visit #1042 on Sat 10 Oct, 3:00 PM is cancelled. Please do not travel.

Sent by the kill switch (screen A8).

To user: booking confirmed
CareNest: Booking #1042 confirmed. Nurse Anita S. will visit on Sat 10 Oct at 3:00 PM.

Sent the moment the user pays.

To user: nurse changed
CareNest: Your nurse for booking #1042 is now Kavita R. Date and time are unchanged.

Sent when the admin reassigns.

To user: cancelled with refund
CareNest: Booking #1042 is cancelled. Reason: nurse unwell. Rs 1,600 will be refunded in 5 to 7 working days.

Sent by the kill switch.

These SMS need an approved (DLT) message template on the SMS account before they can be sent. Today only the login code SMS is set up.

Questions for you

The wireframes assume the answer shown under each. Tell us where you want something different.

  1. How much notice does a booking need?Assumed: 3 hours, one value for all services (screen A13).
  2. How many days ahead can a user book?Assumed: 7 days. Today the app allows tomorrow only.
  3. Can the user cancel from the app?Assumed: no. Only the admin cancels, and the user calls support (screen 20).
  4. Is the refund always full?Assumed: yes, even if the visit has started (screen A8).
  5. How is a visit marked started and finished?Assumed: automatically at the booked start and end time, since there is no nurse app (screen A5).
  6. What if a nurse has no working hours set?Assumed: that nurse cannot be booked until the admin sets them (screen A10).
  7. What if the chosen gender is not free?Assumed: the option is disabled and the user changes the time (screen 13).
  8. Should bookings be limited to a service area?Assumed: no limit yet. If you only serve certain cities or a distance from your centre, the app can refuse a pin outside it (screen 14b).
  9. Which map service?Assumed: Google Maps. It has the best address search in India, and is billed by usage beyond its free allowance.
